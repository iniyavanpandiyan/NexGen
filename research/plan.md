# CBSE YouTube Channel - Project Plan

## Overview
Create a YouTube channel using **Remotion** to produce quick learning video clips from CBSE textbooks.

## Source Identified: NCERT24.com
- **URL:** https://ncert24.com
- **Status:** ✅ Fully accessible, no authentication required
- **Content:** PDF textbooks (actual book content) - NOT chapter-wise HTML pages
- **Coverage:** Classes 9-12, all subjects and streams
- **Key Finding:** Chapter-wise URLs are landing/index pages only; actual content is in downloadable PDFs

## Content Strategy
### Target Audience: Class 9-12 students preparing for CBSE board exams
### Video Format: Vertical Shorts (Reel-style, 60 seconds)
### Content Breakdown:
- Textbooks broken into multiple short videos per chapter
- AI Text-to-Speech for narration
- Daily upload target

### Priority Subjects:
1. **Mathematics** (Class 9-12) - Most popular, formula-heavy
2. **Physics** (Class 11-12) - Visual explanations needed
3. **Chemistry** (Class 11-12) - Reaction mechanisms
4. **Science** (Class 9-10) - Concept explainers
5. **Social Science** (Class 9-12) - History, Geography, Civics
