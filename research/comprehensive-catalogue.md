## ⚠️ Important Notes

### What Changed from Previous Catalogue:
1. **Chapter-wise HTML content does NOT exist** - The "chapter" URLs on ncert24.com are landing/index pages only, not actual textbook content
2. **The real source is PDF textbooks** - All actual book content is available as downloadable PDFs in the `/assets/ots/pdf/` directory
3. **English books (Beehive, First Flight)** exist as HTML landing pages but contain NO actual chapter text - they only have chapter navigation links
4. **Sanskrit books** are NOT available as PDFs on this site
5. **Hindi books** are partially available - Class 9-10 Hindi has no PDFs; Class 11-12 Hindi social science subjects have Hindi versions

### PDF Extraction Strategy:
- PDFs range from ~20-66 MB per book
- Use PDF text extraction (e.g., pdfplumber, PyPDF2) to get readable text
- Extract key concepts, formulas, and diagrams for video narration
- PDF format is ideal for automation since it's structured content
