## URL Patterns Summary

### Chapter Content (Rich Text)
```
https://ncert24.com/ncert-books/ncert-books-class-{X}-subject-chapter-{Y}
```
Examples:
- `https://ncert24.com/ncert-books/ncert-books-class-9-maths-chapter-1`
- `https://ncert24.com/ncert-books/ncert-books-class-9-science-chapter-1`

### Alternative Chapter Pattern (Class 10+)
```
https://ncert24.com/ncert-books-class-{X}-subject-chapter-{Y}
```
Examples:
- `https://ncert24.com/ncert-books-class-10-maths-chapter-1`

### Class 12 Maths (Split into Parts)
```
https://ncert24.com/ncert-books/ncert-book-class-12-maths-part-{X}-chapter-{Y}
```
Examples:
- `https://ncert24.com/ncert-books/ncert-book-class-12-maths-part-1-chapter-1`
- `https://ncert24.com/ncert-books/ncert-book-class-12-maths-part-2-chapter-1`

### Book PDF Downloads
```
https://ncert24.com/ncert-books/{subject}-class-{X}-book-pdf
```
Examples:
- `https://ncert24.com/ncert-books/class-9-maths-ncert-book-pdf`
- `https://ncert24.com/ncert-books/class-11-physics-book-pdf`
